# 🍊 Citrus Studio

Секвенсор/DAW в браузере, построенный по образцу FL Studio 20. Чистый HTML + CSS + JavaScript,
никакой сборки и никаких внешних библиотек: достаточно открыть `index.html`.

Весь звук синтезируется на лету через Web Audio API — сэмплов в комплекте нет,
но свои можно загрузить в канал-сэмплер.

## Как устроено (по мотивам FL Studio)

| Окно FL Studio | Здесь | Клавиша |
|---|---|---|
| Playlist | аранжировка паттернов по трекам | `F5` |
| Channel Rack | степ-секвенсор с каналами | `F6` |
| Piano Roll | редактор нот | `F7` |
| Mixer | 12 инсертов + мастер, цепочки эффектов | `F9` |

Как и в FL, **шаг в секвенсоре — это обычная нота**: то, что нарисовано в Channel Rack,
видно и редактируется в Piano Roll, и наоборот. Паттерн хранит ноты всех каналов сразу,
а Playlist расставляет паттерны по времени.

## Возможности

**Инструменты** (синтезируются процедурно)
- Ударные: Kick, Snare, Clap, Hat, Tom, Cymbal, Rim — с параметрами тона, затухания, панча, металличности
- `Trio Osc` — синтезатор на трёх осцилляторах: волны, расстройка, унисон, фильтр с огибающей, ADSR
- Сэмплер: загрузка своего аудиофайла, воспроизведение с транспонированием, ADSR, цикл
- Готовые пресеты: Bass, Reese Bass, Pluck, Lead, Pad, Organ, Chip Square, Kick 808 и др.

**Микшер**
- 12 инсертов + мастер, громкость, панорама, mute/solo, индикаторы уровня
- Эффекты: EQ 3, фильтр, дисторшн, хорус, дилей (пинг-понг), реверб (генерируемая импульсная характеристика), компрессор
- Лимитер на мастере

**Секвенсор и транспорт**
- Режимы `PAT` (паттерн по кругу) и `SONG` (вся аранжировка)
- Темп 20–300 BPM, свинг, метроном
- Планировщик с упреждением на Web Audio — стабильный тайминг, не зависящий от отрисовки

**Проект**
- Сохранение/загрузка в `.citrus` (JSON), автосохранение в localStorage
- Отмена/повтор действий (`Ctrl+Z` / `Ctrl+Shift+Z`)
- Экспорт в WAV офлайн-рендером (быстрее реального времени), 44.1/48 кГц

## Управление

**Транспорт**
- `Пробел` — старт/пауза, `Ctrl+L` — переключить PAT/SONG
- Поле BPM: тянуть мышью, колесо, двойной клик — ввод числа

**Channel Rack**
- ЛКМ по шагу — поставить, ПКМ — стереть, тянуть — рисовать подряд
- Клик по имени канала — настройки инструмента справа, ПКМ — меню (клонировать, заполнить, случайно, удалить)
- Кружок слева — вкл/выкл канал, ПКМ по кружку — соло

**Piano Roll**
- ЛКМ — поставить ноту, ПКМ — стереть кистью, тянуть за правый край — длина
- Колесо — вертикальный скролл, `Shift`+колесо — горизонтальный, `Ctrl`+колесо — зум
- Нижняя полоса — velocity, `Delete` — удалить выделенное

**Playlist**
- ЛКМ — поставить клип выбранного паттерна, тянуть — двигать, ПКМ — удалить
- Клик по линейке — перемотка

**Игра с клавиатуры**
- Нижний ряд `Z S X D C V G B H N J M` и верхний `Q 2 W 3 E R 5 T 6 Y 7 U` — две октавы
- `[` и `]` — сменить октаву
- Кнопка ● (запись) + проигрывание — ноты пишутся в текущий паттерн выбранного канала

## Структура кода

```
index.html
css/style.css
js/
  util.js              — DOM-хелперы, крутилки, попапы, шина событий
  project.js           — модель проекта, пресеты, демо-трек, история, сериализация
  audio/
    instruments.js     — синтез ударных, Trio Osc, сэмплер
    effects.js         — эффекты микшера и цепочки
    engine.js          — аудиограф и планировщик воспроизведения
    export.js          — офлайн-рендер и кодирование WAV
  ui/
    channelrack.js  pianoroll.js  playlist.js  mixer.js  inspector.js  browser.js
  main.js              — транспорт, вкладки, горячие клавиши, цикл отрисовки
```

Инструменты и эффекты описаны декларативно (`defs` с параметрами), поэтому окно настроек
строится автоматически, а один и тот же код играет и вживую, и при рендере в WAV.
