# Ausnichtsman's polygon

Сцена на голом WebGL 1: ни библиотек, ни внешних файлов. Всё — геометрия,
текстуры, звук — считается процедурно прямо в браузере.

Открыть: `index.html` (двойной клик или `python3 -m http.server`).

## Что внутри

**Невада.** Три поверхности висят над пустыней: цилиндр, лента Мёбиуса и
дважды перекрученная лента. По каждой можно провести среднюю линию, разрезать
вдоль неё и развести куски — при разведении лента не пересекает саму себя.
Из конца линии торчит нормаль: на ленте Мёбиуса она переворачивается, на
остальных двух возвращается как была.

Вместо солнца квазар с аккреционным диском, джетами и линзированной дугой.
В стороне чёрная дыра: искривление лучей, синий сдвиг, замедление времени —
подойти можно до отметки, где ваши часы идут в двадцать раз медленнее
дальних. Рядом ветряк (у дыры он раскручивается), бак с водой, палатка с
котом, джазом и дневником. Сутки идут пять минут, ночью виден Млечный Путь.

**Космос.** В ракету садятся по E. Подъём строго вертикальный, две минуты до
двадцати километров; кресло вжимает перегрузкой, звук двигателя тает вместе с
атмосферой. Дальше выбирается цель: квазар в двух миллионах километров или
соседняя планета в четырёхстах тысячах. Разгон и торможение по 100 g,
искривление пространства включается только ближе 200 000 км.

**Полигон Гамма.** Своя планета: чернозём, трава, роща, море, шоссе на пять
километров и город в конце. Есть золотой бассейн, машина и советник в чёрном
балахоне, с которым можно поговорить с клавиатуры. Ядерное испытание —
кнопка или B: изделие уходит на мишенное поле, вспышка слепит, гриб
поднимается на семьсот метров, ударная волна валит с ног и оставляет звон в
ушах, постройки разваливаются на блоки, лес горит.

## Сборка

Исходник разложен по частям в `src/`, чтобы с ним можно было работать.

```
cd src && node build2.js
```

Скрипт склеивает части в нужном порядке и кладёт рядом два файла:
`polygon-mobius.html` — без обёртки, для публикации артефактом, и
`wrapped2.html` — обычная страница для локального просмотра.

Порядок частей важен: `p2` (математика и помощники) → `p2b` (звук шагов) →
`p3` (шейдеры) → `p4`, `p4b` (ландшафт Невады, дыра, руки) → `p7`
(палатка, кот, строитель мешей) → `p9` (ракета, карты планет) → `p10`
(перелёт и взрыв) → `p11` (мир Гаммы) → `p12` (советник, отброс, звон) →
`p5` (сборка сцены и отрисовка) → `p8` (джаз и дневник) → `p6` (звук,
управление, цикл кадров).

## Управление

| Действие | Клавиши | Экран |
| --- | --- | --- |
| Идти | W A S D | джойстик слева |
| Осмотреться | тянуть | тянуть |
| Взять фигуру, сесть, помыть руки | E | нажать |
| Отпустить | Esc | кнопка |
| Испытание на Гамме | B | «Сбросить бомбу» |
| Поговорить с советником | T | — |
| Машина: газ, тормоз, руль | W S A D | педали в панели |
